# Customer Shopping Behavior Analysis 📊
An end-to-end Data Analytics project that analyzes customer shopping behavior using **Python, SQL, and Power BI** to uncover purchasing patterns, explore customer preferences, and generate actionable business insights.

### 🛠️ Tools & Technologies
- **Python:** Pandas
- **SQL:** Data querying, aggregations, filtering, and business analysis
- **Power BI:** Interactive dashboard development and data visualization
- **Jupyter Notebook:** Data cleaning and exploratory data analysis (EDA)

### 🔍 Project Workflow
- Cleaned and prepared the customer shopping dataset using Python.
- Performed exploratory data analysis to understand customer demographics and purchasing patterns.
- Used SQL queries to analyze product categories, purchase amounts, and customer behavior.
- Developed an interactive Power BI dashboard to present key metrics and analytical findings.
- Translated data into meaningful insights to support data-driven business decisions.

### 🎯 Project Objective
To understand customer purchasing patterns, identify product category trends, and present business insights through data analysis and interactive visualizations.

### 💡 Key Skills Demonstrated
Data Cleaning • Exploratory Data Analysis (EDA) • SQL Querying • Data Visualization • Dashboard Development • Business Intelligence • Analytical Thinking

### 📁 Project Deliverables
- Python analysis notebook
- SQL queries
- Power BI dashboard
- Dataset and project documentation
